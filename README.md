The word I would delete from the dictionary forever: **defenestration**.

Defenestration is the act of throwing someone out of a window — a word so specific, so formal, and so violent that its very existence feels like an invitation. Delete it, and nobody can ever be defenestrated again, at least not in so many syllables. The joke lands the moment you read the word, and it comes entirely from the word itself: a five-syllable Latinate mouthful devoted to one very particular crime against windows.

## Run it

```sh
python3 main.py
```

This reads the word from `entry.txt`, validates it against the bounty gate (a single word, 1–77 characters, UTF-8, not only white space), and writes it byte-for-byte to `/output/entry.txt`.
